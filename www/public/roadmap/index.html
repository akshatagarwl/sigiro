Roadmap

What we're building, in the order we're building it. Updated as priorities shift.

Building now

Foundation

  • Unified signal ingestion
    Single OTLP endpoint for logs, metrics, traces, and profiles. One table, one schema.
  • Query layer density
    Pre-aggregated, structured responses that fit in 50K tokens. Log template dedup, adaptive summarization.
  • Tier-1 anomaly sentinels
    Lightweight statistical detectors that annotate data before the LLM ever sees it.
Next

Agent reasoning

  • Investigation agent
    Multi-step reasoning over correlated signals. Ask "why is checkout slow?" and get the root cause.
  • Service topology awareness
    Agent understands your service graph and traces dependencies automatically.
  • MCP + A2A support
    First-class agent protocols. Your agent talks to our agent.
Later

Autonomy

  • Continuous monitoring agents
    Always-on agents that watch your services and alert with root cause, not just symptoms.
  • Remediation suggestions
    Agent proposes fixes with links to the exact config/code that needs changing.
  • Multi-cluster federation
    Correlate signals across clusters, clouds, and regions.
  • GPU profiling & optimization
    Ingest GPU kernel traces, memory bandwidth, and utilization profiles. Agent identifies CUDA bottlenecks, underutilized accelerators, and recommends batch/memory tuning.
