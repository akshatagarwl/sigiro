本页列出 `src/config.rs` 中的配置。表格中的数值、单位和禁用语义与英文原文一致。修改服务端设置后必须重启。

**运维摘要：** `SIGIRO_RETENTION_DAYS=7` 表示自动保留 7 天，`0` 禁用清理。`SIGIRO_MAX_DISK_BYTES=0` 表示不设磁盘上限。超过上限时以 HTTP 507 / gRPC resource_exhausted 拒绝新摄取；下次采样发现占用低于上限的 90% 后恢复。连续 3 次检查点失败会停止接收该项目的数据，成功后恢复。`block` 会等待队列腾出空间；`drop-newest` 在队列满时丢失数据但返回成功。配置证书和密钥仅为 4317/4318 启用 TLS，9999 的 API 仍是明文。Open 模式不认证；JWT 模式必须同时配置 issuer、audience 和 JWKS URL，不支持简单的固定 bearer 令牌。

This reference describes the current `src/config.rs` surface. Set environment variables **before starting** `sigiro serve`; server settings require a restart to change (including the on-demand secrets, which are read on requests but are not a supported hot-reload mechanism). Client settings are read by the CLI; restart the client command after changing them. Numeric types below are unsigned integers unless stated otherwise. An empty value is **not** the same as an unset value for settings marked “unset”. Only four settings have `serve` flags; all other server settings are environment-variable-only.

## 服务端监听器、存储和安全

| Variable                                                             | Default; valid value and behavior                                                                                                                                                                                                                            |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `SIGIRO_DATA_DIR`                                                    | Platform data directory (`~/.local/share/sigiro` on Unix); filesystem path. Override with `--data-dir`. Persist this volume in Docker.                                                                                                                       |
| `SIGIRO_HTTP_PORT`                                                   | `9999`; TCP port (0–65535, though 0 selects an OS-assigned port). Override with `--http-port`. Main API is **plaintext**, even with native OTLP TLS.                                                                                                         |
| `SIGIRO_GRPC_PORT`                                                   | `4317`; TCP port. Override with `--otlp-grpc-port`.                                                                                                                                                                                                          |
| `SIGIRO_OTLP_HTTP_PORT`                                              | `4318`; TCP port. Override with `--otlp-http-port`.                                                                                                                                                                                                          |
| `SIGIRO_TLS_CERT`, `SIGIRO_TLS_KEY`                                  | Both unset: plaintext OTLP. Set **both** to readable PEM certificate-chain and private-key file paths to enable TLS on OTLP gRPC and OTLP HTTP. A missing partner or invalid/unreadable file fails startup. No mTLS.                                         |
| `SIGIRO_AUTH_ISSUER`, `SIGIRO_AUTH_AUDIENCE`, `SIGIRO_AUTH_JWKS_URL` | All empty: **Open** mode (no per-request authentication). Set all three for JWT resource-server validation; partial configuration fails. Distributed mode requires JWT. There is **no simple static bearer-token mode**. TLS does not enable authentication. |
| `SIGIRO_ADMIN_TOKEN`                                                 | Unset: distributed tenant/key provisioning mutation endpoints disabled. Otherwise admin bearer secret; **not** a general ingest/query token.                                                                                                                 |
| `SIGIRO_CATALOG_URL`                                                 | Unset: local DuckLake file catalog. PostgreSQL `postgres://` or `postgresql://` URL selects distributed catalog; an explicitly empty value is invalid. Treat credentials as secrets.                                                                         |
| `SIGIRO_S3_BUCKET`, `SIGIRO_S3_REGION`, `SIGIRO_S3_ENDPOINT`         | Empty: no S3. For S3 storage set bucket and region with a PostgreSQL catalog; S3-compatible stores require an absolute HTTP(S) origin endpoint (no path/query/credentials).                                                                                  |
| `SIGIRO_S3_KEY_ID`, `SIGIRO_S3_SECRET`                               | Empty: fall back respectively to `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`. Required when S3 bucket is set. Keep the secret out of logs and shell history.                                                                                             |
| `SIGIRO_EXTENSION_DIR`                                               | Empty: extension cache under data directory; filesystem path to writable/pre-seeded DuckDB extension directory.                                                                                                                                              |
| `SIGIRO_ALLOW_UNSIGNED_EXTENSIONS`                                   | `false`; boolean. `true` allows unsigned local DuckDB extensions; do not enable for untrusted files.                                                                                                                                                         |
| `SIGIRO_HOSTED_DATA_DIR`, `SIGIRO_DUCKDB_CACHE_DIR`                  | Hosted-mode filesystem paths, defaults `/var/lib/sigiro/telemetry` and `/var/cache/sigiro/duckdb`; not the ordinary self-hosted data directory.                                                                                                              |
| `SIGIRO_OTEL_AUTH_KEY`                                               | Empty; credential for Sigiro's **own self-telemetry export**, not server request authentication.                                                                                                                                                             |
| `SIGIRO_ALERT_WEBHOOK_URL`, `SIGIRO_ALERT_WEBHOOK_TOKEN`             | Empty URL disables webhook delivery; optional token authenticates outgoing alert webhook requests, not incoming OTLP/API calls.                                                                                                                              |
| `SIGIRO_PYROSCOPE_ENDPOINT`                                          | Empty disables profiling export; otherwise Pyroscope endpoint URL.                                                                                                                                                                                           |

## 摄取、保留期限和查询限制

| Variable                                                       | Default; valid value and behavior                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SIGIRO_RETENTION_DAYS`                                        | `7` days; unsigned 32-bit integer, `0` disables automatic retention. An hourly cleanup deletes old timestamped telemetry rows across the writer's signal tables; DuckLake checkpoint/snapshot expiry subsequently reclaims physical files (DELETE alone need not release bytes). Derived/admin data is not promised to follow this cutoff.                                               |
| `SIGIRO_MAX_DISK_BYTES`                                        | `0` (disabled); unsigned 64-bit raw bytes. Periodically sampled **local** data-directory soft cap; at/above cap rejects new ingest with HTTP **507** or gRPC **resource_exhausted**. Resumes after a sample sees usage **below 90%**. Queued/in-flight data may overshoot: leave disk headroom. S3 Parquet and external PostgreSQL catalog bytes are **not** counted.                    |
| `SIGIRO_DISK_SAMPLE_SECONDS`                                   | `30` seconds; unsigned 64-bit integer greater than zero. Sampling only runs when retention or the cap is enabled. A cap trip triggers single-flight retention cleanup when retention is enabled; the next sample decides recovery.                                                                                                                                                       |
| `SIGIRO_MAX_CHECKPOINT_FAILURES`                               | `3` consecutive failures per project; unsigned 32-bit integer. At threshold, shed that project's ingest with HTTP 507 / gRPC resource_exhausted and report degraded health; a successful checkpoint resets the counter and re-enables ingest. `0` disables shedding, **not** failure reporting. Particularly important when the PostgreSQL catalog grows outside the local disk sampler. |
| `SIGIRO_MAX_INGEST_BODY_BYTES`                                 | `8388608` bytes (8 MiB); positive integer. Maximum decoded gRPC message and decompressed OTLP HTTP body.                                                                                                                                                                                                                                                                                 |
| `SIGIRO_BACKPRESSURE_POLICY`                                   | `block` or `drop-newest`. `block` awaits space in the bounded per-project queue and may slow clients; `drop-newest` discards the incoming message on a full queue, logs data loss, and **returns success** (not 429). Neither policy provides durable buffering; configure collector sending queues/retries for outages.                                                                 |
| `SIGIRO_FLUSH_INTERVAL_SECS`                                   | `1` second; unsigned 64-bit interval. Timer for flushing buffered rows; row/byte thresholds may flush sooner.                                                                                                                                                                                                                                                                            |
| `SIGIRO_FLUSH_ROW_THRESHOLD`                                   | `10000` rows; unsigned integer, across signal tables per project.                                                                                                                                                                                                                                                                                                                        |
| `SIGIRO_FLUSH_BYTE_THRESHOLD`                                  | `8388608` bytes (8 MiB); unsigned integer, buffered per project.                                                                                                                                                                                                                                                                                                                         |
| `SIGIRO_SHUTDOWN_TIMEOUT_SECS`                                 | `5` seconds per project's drain; unsigned 64-bit integer greater than zero. Slow storage may exceed this and leave buffered data unflushed.                                                                                                                                                                                                                                              |
| `SIGIRO_DUCKDB_THREADS`                                        | Available host parallelism; positive integer, DuckDB threads per project database.                                                                                                                                                                                                                                                                                                       |
| `SIGIRO_DUCKDB_MEMORY_LIMIT`                                   | `400MB`; nonempty DuckDB memory-size string (for example `8GB`), per project database. Increase with available RAM when diagnosis/query runs out of memory.                                                                                                                                                                                                                              |
| `SIGIRO_QUERY_TIMEOUT_SECONDS`                                 | `30` seconds; unsigned 64-bit integer greater than zero, per-query watchdog timeout.                                                                                                                                                                                                                                                                                                     |
| `SIGIRO_MAX_RESULT_ROWS`                                       | `100000` rows; positive integer, maximum `/v1/query` response rows before truncation.                                                                                                                                                                                                                                                                                                    |
| `SIGIRO_QUERY_ROW_CAP`                                         | `1000000` rows; positive integer, per-edge federated partial result cap.                                                                                                                                                                                                                                                                                                                 |
| `SIGIRO_QUERY_SURFACE`                                         | `none` or `quack`; `quack` exposes cross-project DuckDB query serving on an edge.                                                                                                                                                                                                                                                                                                        |
| `SIGIRO_QUACK_BIND`, `SIGIRO_QUACK_PORT`, `SIGIRO_QUACK_TOKEN` | `127.0.0.1`, `7777`, empty token. Bind must be an IP address; port is TCP. Token is for the **quack surface only**, not OTLP/main API. Do not expose plaintext quack to an untrusted network.                                                                                                                                                                                            |

There is no universal minimum for the flush row/byte thresholds beyond their unsigned types; `0` is **not documented as an off switch** for these settings. A typed value can still fail at the underlying subsystem. Settings without an explicit disable value in the table do not have a supported disable convention.

## 客户端和自监控设置（非服务端认证）

| Variable                                           | Default; valid value and behavior                                                                                                            |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `SIGIRO_ENDPOINT`                                  | Empty selects localhost (`http://localhost:9999`) unless an OAuth login selects hosted; URL for client commands and MCP operational calls.   |
| `SIGIRO_ACCESS_TOKEN`                              | Empty; outgoing client bearer credential. Global `--token <TOKEN>` overrides it. Does **not** configure incoming authentication.             |
| `SIGIRO_EDGES`                                     | Empty: discover Tailscale peers; otherwise comma-separated `name=host:port` edge overrides for federated `sigiro query`, alongside `--edge`. |
| `SIGIRO_DOCS_MCP_URL`                              | `https://sigiro.com/mcp/docs`; public docs MCP URL, no Sigiro credential forwarded.                                                          |
| `OTEL_SERVICE_NAME`, `OTEL_EXPORTER_OTLP_ENDPOINT` | `sigiro`, empty; Sigiro's self-instrumentation service name and exporter endpoint. Not `SIGIRO_*`, but declared in `src/config.rs`.          |
| `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`       | Empty; S3 credential fallback when the matching `SIGIRO_S3_*` value is empty.                                                                |

## Docker：OTLP 摄取 TLS

Use your own certificate with a SAN matching the hostname your clients use. This example maps OTLP only to the host and keeps the plaintext main API loopback-only; adapt the image tag and data volume for your deployment.

```sh
docker run --name sigiro \
  -v sigiro-data:/var/lib/sigiro \
  -v "$PWD/certs:/certs:ro" \
  -e SIGIRO_TLS_CERT=/certs/server.pem \
  -e SIGIRO_TLS_KEY=/certs/server-key.pem \
  -p 127.0.0.1:9999:9999 -p 4317:4317 -p 4318:4318 \
  ghcr.io/sigiroai/sigiro:latest serve
```

Configure gRPC exporters for `https://your-host:4317` and OTLP HTTP exporters for `https://your-host:4318` (signal paths such as `/v1/traces` for explicit HTTP endpoints). Clients must trust the signing CA or explicitly trust a self-signed cert and verify the matching DNS SAN. Do **not** disable certificate verification. The main API on `9999` remains `http://` inside the host; terminate HTTPS for remote query/API clients at a reverse proxy. TLS protects transport, **not** access: Open mode still accepts any request reaching the listeners. Configure all three JWT settings or isolate the ports behind a trusted network. `tests/grpc_tls_test.rs` covers the real server TLS gRPC wire path, TLS HTTP handshake, and plaintext main API. The exact Docker command and image tag are not independently integration-tested.
