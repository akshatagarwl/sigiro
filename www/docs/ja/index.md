sigiro は OpenTelemetry のトレース、ログ、メトリクス、プロファイルを保存し、それらに対する
SQL に答えます。エージェントを第一に設計しており、すべての答えはエージェントにも人にも再実行できる
クエリです。ホスト型ワークスペースには、人のための読み取り専用の
[ダッシュボード](https://sigiro.com/dashboard/) もあります。

初めてで、ご自身のアプリのデータを sigiro.com に送りたい場合は、[ホスト型 sigiro への
テレメトリ送信](/docs/how-to/hosted-onboarding) から始めてください。代わりにご自身のマシンで
動かしたい場合は、[クイックスタート](/docs/tutorials/quickstart) から始めてください。

本ドキュメントは 4 つのパートで構成されています。各パートはそれぞれ異なる種類の問いに答えるため、
いま抱えている問いに合致するパートへ進んでください。

## チュートリアル

レッスンです。sigiro の知識を前提としていないため、まずこのパートを読んでください。
各手順に従って進めると、手順ごとに結果を確認できます。

- **[クイックスタート](/docs/tutorials/quickstart)** — ご自身のマシンでサーバーを起動し、
  テレメトリを送信して、最近の失敗を SQL で照会します。所要時間は 5 分です。

## ハウツーガイド

1 つのタスクを実行するための手引きです。やりたいことが決まっていて、
それを実現する手順が必要なときにこのパートを読んでください。

- **[エージェントでコードを計装する](/docs/how-to/install-with-ai)** — エージェントに
  プロンプトを 1 つ渡します。エージェントが OpenTelemetry をサービスに接続し、sigiro に向けて設定します。
- **[Agent Auth でエージェントをオンボーディングする](/docs/how-to/agent-auth)** —
  委任マシン ID を登録し、必要な capability だけを承認してから、鍵をローテーションまたは失効させます。
- **[ホスト型 sigiro へのテレメトリ送信](/docs/how-to/hosted-onboarding)** — Web または
  `sigiro signup` でサインアップし、アプリから当社が運用するホストへ OTLP を送信して、
  ダッシュボードで確認します。
- **[エージェント自身のテレメトリを sigiro に送信する](/docs/how-to/agent-telemetry)** —
  Claude Code、Codex、Hermes Agent、Pi を sigiro に向けて設定します。
- **[エージェントをデバッグして最適化する](/docs/how-to/debug-agent-performance)** —
  セッションが時間とトークンをどこで使ったかを見つけ、無駄な作業を取り除き、次の実行と
  根拠に基づいて比較します。
- **[sigiro を Executor に接続する](/docs/how-to/executor)** — OpenAPI の API または
  ドキュメント MCP サーバーをエージェントゲートウェイに取り込みます。
- **[Pyroscope プロファイルを sigiro に送信する](/docs/how-to/send-profiles)** — 検証済みの
  プロファイリング SDK を設定し、プロファイルの行を SQL で読み返します。

## リファレンス

このマシンに関する事実です。名前、型、上限を確認するために、作業中にこのパートを読んでください。

- **[API リファレンス](/docs/reference)** — サーバーの `/openapi.json` が現在記述している
  HTTP 操作です。このドキュメントに含まれないインジェストプロトコル（Pyroscope 互換ルートを含む）は
  ハウツーガイドで説明しています。
- **[CLI リファレンス](/docs/reference/cli)** — 7 つのサブコマンド、すべてのフラグ、
  そしてそれらが読み取るすべての環境変数です。

`/openapi.json` を読み取るエージェントには、当社からの他の情報は必要ありません。

## 解説

sigiro がこのように動作する理由です。理由、コスト、そして代替案を知りたいときに
このパートを読んでください。ターミナルは必要ありません。

- **[テーブルについて、そしてどのマシンを記述しているか](/docs/explanation/tables)**
  — 保存されるシグナルと、別のマシンのデータで回答しないための方法。
- **[廃止された異常検出と診断の設計](/docs/explanation/evidence)** — 過去の記録です。
  順位付けされた結果の設計は削除されました。代わりに SQL を使ってください。
- **[廃止されたデプロイ診断の設計](/docs/explanation/deploys)** — 過去の記録です。
  デプロイの自動検出は削除されました。`service.version` は引き続きクエリできます。
