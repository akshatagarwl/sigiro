# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
(private vulnerability reporting). If that is unavailable, email
hello@sigiro.com with "SECURITY" in the subject.

Include what is affected (self-hosted binary, hosted service, CLI, or website),
the version or commit, steps to reproduce, and the impact you expect.
Do not test against other users' data or run load tests against sigiro.com.

We aim to acknowledge reports within 3 business days and to agree a disclosure
date with you once a fix is ready.

## Supported versions

Only the latest release of the `sigiro` binary and the current hosted service
receive security fixes.
