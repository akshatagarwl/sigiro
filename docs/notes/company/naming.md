# Company Name Candidates

## Systematic Search Methodology

Names were found via three parallel tracks:

1. **Brute-force generator** — all pronounceable 2-syllable combinations (64k candidates), parallel RDAP checks against Verisign (.com) and Google (.dev). Result: all clean 4-char .com names are squatted; 5-char .com availability ~10% but mostly garbage combos.
2. **English word search** — short real English words with observability meaning checked across .com/.dev/.app. Most squatted.
3. **Portmanteau from strong roots** — `sig-` (signal), `ver-` (verify), `clar-` (clarity), `luc-` (light), `trac-` (trace), `van-` (vantage), `scop-` (scope), `sent-` (sentinel) + suffixes (-ia, -io, -ex, -al, -in, -era). DNS-verified against .dev.

**[[designs/pricing.md|Pricing]] (Porkbun API — Cloudflare similar):**
- `.com` — $11.08/yr register + renew
- `.dev` — $10.81 register / $12.87 renew
- `.app` — $10.81 register / $14.93 renew
- `.ai` — $82.70/yr ❌ over budget
- `.io` — $28-52/yr ❌ over budget

**Conclusion on .com:** all good 4-6 char names are squatted. `.dev` at $11-13/yr is the right primary TLD for a developer tool anyway.

tldx myname -t dev,ai,com -a       # check all 3 TLDs
